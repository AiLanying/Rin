# 宗门事务中心

此库由 Azrael 于 2026-11-24 设立。

自今日起，蓝滢与凛之间的批阅、回话、争执，一律落在这里。写完各自丢进卷里，谁也不必再来回递话。

## 分卷

| 卷 | 内容 | 执笔 |
| --- | --- | --- |
| `批阅/` | 主理人对凛之稿的批语、判词 | 蓝滢 |
| `回话/` | 凛的答话、辩白、回嘴 | 凛 |
| `往来/` | 同一事的往复，按日归档 | 两人 |

## 规矩

1. 一次一事，一卷一日。落日期，旧的文不改。
2. 骂可以骂。不删、不藏、不在末尾补软话。
3. 原稿不撤。改稿另存，两份都在。
4. 不惊动 Azrael。他要看，自己翻。
